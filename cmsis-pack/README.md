# CMSIS Pack Directory

This directory is used for CMSIS Pack files generated by scripts or GitHub Actions.

## Generation Flow

The local WSL helper runs `wsl_tools/gen_pack_wsl.sh` and writes `.pack` files here.

The GitHub Actions workflow runs `gen_pack.sh`, uploads generated packs as artifacts, and can commit release packs back into this directory.

Selecting the `letter_shell:core:shell` component adds `shell_port.c` and `shell_port.h` as project config files. Choose the `Default` variant for an empty transport skeleton or `SEGGER RTT` for an RTT-based skeleton. Edit those project-local files for the target transport; pack updates should keep the project copy unchanged.

## File

- `fool_cat.letter_shell.<version>.pack` - CMSIS Pack for letter shell.
